# Gw2Analytics — archived

- **Closure date:** 2026-10-11
- **Status:** discontinued
- **Reason:** the existing GW2 WvW ecosystem (Elite Insights, Drevarr's GW2 EI
  Log Combiner, AxiBridge, WvW Insights) already provides the parsing,
  aggregation, integration and visualization capabilities this project was
  building. Continuing would have meant reimplementing existing tools.
- **This repository** is kept as a read-only archive for historical and
  reference purposes only.
- **Future work** in this area will continue separately under a new,
  independent project: **WIS — WvW Intelligence Service** (upstream-first:
  build intelligence on top of existing ecosystem tools rather than
  reimplementing telemetry).
- **No automatic migration** of Gw2Analytics code into WIS is planned.
  Gw2Analytics is not the default technical foundation for WIS.
